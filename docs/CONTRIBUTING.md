# Contribuição

1. Preserve a branch master como linha principal deste projeto.
2. Não commit de .env, tokens ou credenciais.
3. Não mover regras de negócio para componentes visuais.
4. Toda operação de campo deve considerar conectividade instável.
5. Mudanças de modelo devem preservar compatibilidade ou incluir migração.
6. Teste Web e Mobile antes de considerar uma tela concluída.
